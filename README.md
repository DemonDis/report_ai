# Git Report AI

VS Code расширение для автоматической генерации отчётов о проделанной работе на основе изменений в Git через AI.

## Установка

1. Склонировать репозиторий
2. `npm install && npm run compile`
3. В VS Code: `F5` — откроется новое окно с расширением

Либо упаковать в `.vsix` через `npx vsce package` и установить через «Extensions → Install from VSIX».

## Использование

1. Откройте проект в VS Code (проект должен быть Git-репозиторием)

2. Нажмите `Cmd+Shift+P` (macOS) / `Ctrl+Shift+P` (Windows/Linux)

3. Выполните команду: **Git Report AI: Сформировать отчет**

4. Выберите источник изменений:
   - **Не закоммиченные изменения** — текущие staged/unstaged изменения
   - **Локальные коммиты за период** — введите даты в формате `YYYY-MM-DD`
   - **Изменения между коммитами** — введите хеши коммитов или имена веток
   - **GitLab за период (через API)** — коммиты из GitLab по датам (нужен `gitlabToken`)

5. Расширение соберёт изменения, отправит в AI-модель и покажет отчёт в новом окне

## Конфигурация

В корне проекта должен быть файл `.ilnsk`:

```json
{
  "apiUrl": "https://api.hydraai.ru/v1/",
  "apiKey": "ваш-api-ключ",
  "model": "mistral-nemo",
  "gitlabUrl": "https://gitlab.com",
  "gitlabToken": "ваш-gitlab-token"
}
```

Если файла нет — расширение создаст его автоматически при первом запуске. Останется только вписать `apiKey` и опционально `gitlabToken`.

**Поля:**
- `apiUrl`, `apiKey`, `model` — для доступа к AI-модели
- `gitlabUrl` — адрес GitLab (по умолчанию `https://gitlab.com`)
- `gitlabToken` — Personal Access Token из GitLab (нужен для режима «GitLab за период»). Создаётся в GitLab: `Settings → Access Tokens → Personal Access Tokens` (права `read_api`)

Файл `.ilnsk` добавлен в `.gitignore` — ключи не попадут в репозиторий.

## Формат отчёта

Модель генерирует отчёт в трёх разделах:

- **Что сделано** — краткий маркированный список (2–5 пунктов)
- **Детали** — ключевые технические изменения
- **Вывод** — итог в одном предложении
